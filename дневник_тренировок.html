Инструкция по настройке Firebase:
1. Зайди на https://console.firebase.google.com 2. Создай проект → включи Firestore Database 3. В Project Settings → General скопируй credentials веб-приложения 4. Вставь их в firebaseConfig в начале <script> этого файла 5. В Firestore Database → Rules установи правила: rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /diaries/{diaryKey}/{collection}/{docId} { allow read, write: if request.auth == null; } } } 6.
